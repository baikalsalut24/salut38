# Байкал Салют: сайт и приложение сотрудников
- `site/index.html` — витрина (один файл). `__ORDER_URL__` подставляется при установке.
- `server/` — сервер заказов и приложение сотрудников (Node 18+, без зависимостей).
- `deploy/install.sh` — первая установка на Ubuntu; `deploy/update.sh` — обновление после `git pull`.
